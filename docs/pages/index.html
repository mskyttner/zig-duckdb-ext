zig-duckdb-ext

A DuckDB extension written in Zig — scalar and table functions over the stable v1 C extension API, with an experimental, parallel port to DuckDB's staged, unreleased v2.0 C API.

Maintained by mskyttner · GitHub repository · branch duckdb-v2-api

Installing and Loading

duckdb -unsigned

INSTALL zig_ext FROM 'https://mskyttner.github.io/zig-duckdb-ext/';
LOAD zig_ext;

Not signed, so -unsigned is required — see ADR-0004 for why.

About zig_ext

Demonstrates building DuckDB scalar and table functions in Zig with direct C-API interop (no C++ ABI coupling to DuckDB internals — see ADR-0001), and a comptime framework that generates vectorized callbacks and registration boilerplate from plain per-row Zig functions — see the API docs and the project README for the full picture.

Added Functions

function_namefunction_typedescriptionexample
zig_helloscalar Returns a greeting string. NULL-propagating. zig_hello('Zig') → 'Hello, Zig!'
zig_add_numbersscalar Adds two 64-bit integers, hand-written vectorized callback. zig_add_numbers(2, 3) → 5
ct_add_numbersscalar Same as zig_add_numbers, but registered via the comptime scalar framework from a one-line per-row function. ct_add_numbers(2, 3) → 5
zig_tokenizetable Splits a string by a (possibly multi-character) delimiter, one row per token, 0-based position ordinal. Empty tokens preserved. FROM zig_tokenize('a,,b', ',')
ct_tokenizetable Same as zig_tokenize, registered via the comptime table framework. FROM ct_tokenize('a,b,c', ',')
tp_barscalar Text progress bar. Named parameters on/off/width with defaults, via a SQL macro wrapper. tp_bar(0.7, "on" := '█', "off" := '░', width := 15) → '███████████░░░░'
tp_linescalar Renders a LIST(DOUBLE) as a multi-line ASCII line graph. tp_line([1.0, 3.0, 2.0, 4.0, 2.0])
tp_treemapscalar Renders values/labels as a boustrophedon treemap on a Unicode canvas, area proportional to value. tp_treemap([1.0, 2.0, 3.0], ['small', 'medium', 'large'])
tp_snakemapscalar Two-level hierarchical treemap grouped by a third array, snake-layout panels inside group boxes. tp_snakemap(vals, labels, groups, width := 80, height := 24)

v2 C API port (experimental)

A parallel, in-progress port to DuckDB's staged, unreleased v2.0 C API lives on this same branch — not part of the published zig_ext repository above (DuckDB 2.0 hasn't shipped yet). See the v2 API docs and the migration plan for what's covered: LIST/ARRAY/STRUCT/DECIMAL/ENUM/VARIANT as scalar and cast types, table/aggregate functions, replacement scans, and more.
